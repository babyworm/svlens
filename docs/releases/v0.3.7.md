# svlens v0.3.7 release notes

This patch fixes a missing structural path when a constant ternary arm is
promoted from two-state to four-state. It also ships the connection and CDC
analysis improvements accumulated since v0.3.6, with pinned source checks and
an optional AXI-Lite behavioral benchmark.

## Fixes and analysis improvements

- Constant numeric ternary arms no longer suppress the other arm's data and
  X/Z propagation. Nonconstant state-changing conversions remain conservative.
- Packed-struct fields, fixed field slices, bounded runtime packed-array
  candidates, and whole-interface/modport arrays preserve more ordinal lane
  evidence across module boundaries. Runtime choices remain `approximate`.
- Simple directed module-port forwarding carries bit lanes; clocked D/Q
  assignments remain barriers to combinational connectivity.
- CDC clock/reset provenance, generated-period context, reset mux topology,
  and selected primitive-linked SVA artifacts have source-backed regressions.
  None of these classifications establishes CDC or RDC sign-off safety.

## Accuracy interpretation

The earlier SPI CSID diagnosis was too broad. The guarded output is zero for
all binary inputs, but X/Z inputs can produce X. Its approximate structural
paths are retained; they are not presented as proof of binary value influence.
A four-state regression and pinned SPI references enforce this distinction.

The latest pinned OpenTitan run has 97,550 connection rows, 39/39 selected
positive paths, 7/7 absent-path probes, and the same 20 confirmed sample IDs.
These bounded checks are not whole-SoC precision or recall measurements.
See the [benchmark snapshot](../benchmarks/opentitan-2026-11-16.md).

## AXI benchmark

The optional PULP AXI-Lite 2x2 probe gates 108 structural relations. Its
Verilator testbench completes 14 route cases, 28 writes, and 28 reads, including
eight outstanding-traffic reset recoveries at four clock-phase offsets.
Response corruption and two omitted-reset executions must trigger their
expected assertions before success metadata is written. Diagnostic logs are
retained in the manual benchmark artifact.

Endpoints share reset and discard outstanding traffic. Independent resets
require an integration flush/isolation contract; physical reset timing and
metastability remain outside functional simulation. PULP RTL and Verilator
remain optional benchmark inputs, not normal-build dependencies.

## Compatibility and validation

The CLI and Python package versions are both 0.3.7. CLI version/help contracts
are updated. Connection reports can gain approximate paths and have fewer
recorded mapping gaps; refresh downstream row-count baselines deliberately.
The connection sample manifest pins the new population while retaining its
unchanged selected IDs.
Release archives now include release notes and benchmark snapshots so the
release's evidence and compatibility notes are available with the binary.

Local validation: CTest 758/758; OpenTitan Python tests 40/40; PULP Python
tests 18/18; pinned OpenTitan and PULP probes; the positive AXI simulation and
all three negative controls. Release publication attaches Linux x86_64 and
macOS arm64 archives through the existing tag workflow.
